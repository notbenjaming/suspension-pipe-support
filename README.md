# 悬吊管道支架可视化

独立的浏览器端参数化示意工具，用于展示多层悬吊式钢管支架的三维外观和正视、侧视、俯视示意。项目仅使用 Vite、JavaScript 和 Three.js，不连接 SAP2000 或其他分析软件。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

## 构建与测试

```sh
npm test
npm run build
npm run preview
```

## 配置功能

- 编辑支架宽度 B、横梁层数及各层标高。
- 吊杆使用圆钢，可选择 Ø12、Ø16、Ø20、Ø24、Ø30 标准尺寸或自定义直径。
- 横梁使用真实 L 形角钢截面，可选择 L40×4、L50×5、L63×6 或自定义边长与厚度。
- 三维视图支持旋转和缩放。管线仅以示意线显示，不构造实体管道。
- 配置可导出为 JSON，也可导入并即时验证。重置按钮恢复标注为示例的初始配置。

输入范围：宽度 200–6000 mm；圆钢直径 8–60 mm；角钢边长 20–150 mm、厚度 2–16 mm；标高 200–10000 mm；横梁层间距至少 100 mm。

## 多层吊架受力计算（独立页面）

运行开发服务器后，点击三维主页面顶部的“多层吊架计算”即可在应用内打开计算器面板；也可直接访问 `/suspension-pipe-support/calculator.html`。内嵌面板通过校验同源 origin 与 iframe source 的 `postMessage` 双向同步，不依赖 localStorage。页面计算代码封装在 `src/calculator/` ES modules 中；共享参数映射和消息协议分别位于 `src/sharedParameters.js`、`src/parameterMessages.js`。

双向共享参数为：支架宽度 B（计算器的共享宽度下限；计算出的有效跨距不超过可视化 6000 mm 时回写 B）、吊杆直径，以及 2–5 层的层数和各层横梁标高。层高、宽度或吊杆参数从任一界面变更后，另一界面会收到更新；计算器更新几何参数时可视化三维模型和二维图同步重绘。可视化支持 1–8 层、计算器支持 2–5 层；处于不重叠范围时不强行改动计算器层数，并保留隐藏的计算器分层荷载数据、显示明确提示。切换层数期间隐藏层的管道和附加荷载也保存在共享参数中。

计算器的吊架间距、管道规格/线荷载/排布宽度、集中荷载、型钢截面、型钢自重、弹性模量、受弯容许应力、挠度限值和吊杆材料在三维模型中没有对应输入，因此保留为计算器专属参数，不参与可视化模型计算。两侧横梁截面表示也不兼容：可视化模型是角钢，计算器只校核数据完备的槽钢 / H 型钢；不会将一种截面冒充为另一种或以选择型钢替换可视化角钢。

计算输入和计算模块内部约定使用 mm、kN、kN/m；间距以 mm 输入后显式换算为 m，线荷载与力矩统一分别以 kN/m、kN·m 计算。Tab2 所需的 124 条管道目录记录从附件内嵌 `__PIPE_DATA__.pipes` 提取到 `src/calculator/pipeCatalog.js`，不包括其他计算 tab 的管道类型。按管道类型和规格选择时，直径、宽度与线荷载会自动填入，三项仍可手工覆盖；切换规格时会重新载入该规格目录值。附件旧表管重单位为 kg/m，旧 Excel 采用 `kN/m = kg/m ÷ 100` 的近似转换，界面会显示并应用该显式换算。不要将该历史近似当作精确的 SI 重力换算。

独立计算页的型钢目录位于 `public/steel_query_package/steel_data.json`，包含 821 条来自型钢及结构管规格表的记录。横梁选择器仅开放数据具备正值 `Ix`、`Wx` 与 `weight` 的 C 槽钢（52 条）及 H 型钢（56 条）；L/L2 角钢、方/矩形钢管和圆管均不映射为槽钢或 H 型钢，也不会冒充可校核的横梁。库文件自身未声明单位；按源规格表数值和常用型钢表约定，解析器将 `Ix` 按 cm⁴、`Wx` 按 cm³、`weight` 按 kg/m 读取，明确换算为 mm⁴、mm³ 和 kN/m。若文件缺失、格式不符、记录计数不匹配或没有有效 C/H 记录，页面会显示错误并禁用横梁截面选择；不估算缺失属性。

选定截面后，模型自重按库内 `weight` 自动计入，另可输入附加线荷载。横梁结果按当前计算器的简支梁、x 轴抗弯假设计算弯曲应力需求和分布荷载 / 跨中集中荷载挠度包络（乘现有 1.3 系数）。数据库没有材料弹性模量、受弯容许应力或挠度限值，因此这些字段无默认值，须由使用者按项目条件填写后才会给出满足 / 不满足判定；字段缺失时只显示需求值或“不可判定”。该简化校核不覆盖稳定、剪切、局部屈曲、扭转、连接或规范符合性，仍需专业工程师复核。没有选择型钢时，宽度、荷载、内力和吊杆验算仍可独立进行。

## GitHub Pages 部署

仓库已包含 `.github/workflows/deploy.yml`。工作流在 `main` 分支更新后执行测试、构建并部署 Pages，Vite 的静态资源基路径设置为 `/suspension-pipe-support/`。首次部署前，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 使用边界

此项目是概念可视化，不是结构设计或验证工具。它不检查材料强度、稳定性、连接、挠度、荷载、规范符合性，也不应作为施工依据。初始参数仅为界面演示示例，不构成推荐或规定尺寸。实际工程应由具备资质的专业人员独立设计和复核。
